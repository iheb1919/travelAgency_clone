# TRAVOL — Travel Agency (React Clone)

![Travol Mockup](https://raw.githubusercontent.com/iheb1919/travelAgency_clone/main/public/slider/15.jpg)

A high-performance, modern travel agency web application built with **React 19**, **TypeScript**, and **Tailwind CSS 4**. This project is a complete functional clone of the **TRAVOL — Travel Agency Template** by **DuruThemes**, coded entirely from scratch to demonstrate front-end engineering best practices.

## 🚀 Live Demo
[View Live Site](https://iheb1919.github.io/travelAgency_clone/)

## ✨ Key Features

- **⚡ Optimized Performance**: Custom `LazyImage` component with Intersection Observer for on-demand asset loading.
- **🖼️ Shimmer Loading Effects**: Smooth skeleton screens and shimmer transitions for a premium feel.
- **📱 Fully Responsive**: Seamless experience across mobile, tablet, and desktop devices.
- **🎨 Modern Aesthetics**: Powered by Tailwind CSS 4 with a curated design system and fluid animations.
- **🔄 Navigation**: Client-side routing with React Router, including deep links and breadcrumbs.
- **🏗️ Component Architecture**: Highly modular and reusable component structure using functional React patterns.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Icons**: Custom SVG icons & Lucide-like implementations.
- **Deployment**: GitHub Pages.

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/iheb1919/travelAgency_clone.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
